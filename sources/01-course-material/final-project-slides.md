## Slide 4

- Minimum Requirements
- Create an end-to-end system incorporating data ingest through model monitoring
- Use pipeline services for core processing: Data Preparation, Training, Evaluation, Deployment (or equivalent)
- Incorporate Model Registry, Feature Store (or Vector Store), Model Monitoring, API Gateway
- Show how system architecture would scale to support many users. (Document how you would change the architecture. You do not have to implement.)
- Show incorporation of at least one “unique” service/approach that extends class experience
- Create a demonstration in an application and UI (include Demo Script) with presentation for Dec. 16 final.
- Create 3-5 min video explaining system to a CS student not in Machine Learning
- Submit Architecture (and scaling projection), Price Estimates, Code (well structured and documented), Demo Script (showing results), Presentation, Video, Abstract (½ page) into group GitHub by EOD Dec. 17th, 2026.
