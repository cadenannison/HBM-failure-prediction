HBM Early Warning

Design and build it layer by layer. Each stage makes one design decision, then builds it.
1

Understand the data

Problem framing
Design
What counts as a failure, how far ahead to predict, at which levels
Build
  • Clone the Calchas dataset
  • EDA: error mix, errors per server, row / column / bank clusters
  • One-page task spec
2

Platform

Platform architecture
Design
AWS stack and access model, recorded in an ADR
Build
  • Terraform: VPC, S3 raw / processed / features
  • IAM roles, plus a read-only FleetOps role
  • VPC-only SageMaker
3

Data pipeline

Data & feature pipeline
Design
Data contract: schema, valid ECC types, dedupe rules
Build
  • Glue job: raw logs to windowed CE / UE counts
  • Features per row, column, bank, server
  • Quality gates, then Feature Store
4

Models

Model development
Design
One model per level, threshold set by the cost of its action
Build
  • Logistic regression, random forest, XGBoost
  • Train on early months, test on later
  • Beat the paper's F1, log in MLflow, model card
5

XOps

XOps plan
Design
Promotion rules: recall floor and no regression vs. the champion
Build
  • Model registry with human approval
  • Retraining pipeline: features, train, evaluate, register
  • CI tests for data and models
6

Deploy

Deployment strategy
Design
Action tiers: retire row, spare bank, drain server
Build
  • Hourly batch inference
  • Shadow, then canary, then auto for rows only
  • One-step rollback to the last model
7

Operate

Operating model
Design
SLOs, and what each alert means for the on-call engineer
Build
  • Drift monitors: CE rate, temperature, prediction mix
  • Precision and recall from late-arriving labels
  • Runbook, with hardware ECC as the fallback
8

Justify + govern

Economics + governance
Design
Cost of a crashed job vs. the cost of each action
Build
  • Cost model with ROI sensitivity
  • Audit trail for every prediction and action
  • Human sign-off for server drains
Then Link all 8 layers into one story Exec summary with the dollar impact 15-minute deck + Q&A
